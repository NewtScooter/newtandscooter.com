# Newt & Scooter Studios

Hand-organized static website files for Cloudflare Pages. There is no build step. Upload or deploy the contents of this folder as the site's document root.

## Structure

- `index.html` — homepage
- `contact.html` — contact page
- `privacy.html` — privacy policy
- `site.css` and `site.js` — styles and share-button behavior
- `assets/images/` — logos, Wodipop artwork, and the transparent newt cutout
- `robots.txt` and `sitemap.xml` — search crawler files

The canonical, social preview, structured data, robots, and sitemap URLs are set to `https://newtandscooter.com`. Configure that custom domain for the Cloudflare Pages project after its first deployment.
